# User Guide

This guide covers day-to-day use of PrintBench: finding models, looking after their details, getting files to your slicer and printer, and keeping track of what you have printed.

Not sure what a screen is for? Start with [A Tour of PrintBench](/getting-started/tour). Looking after the instance itself (libraries, users, printers)? That is the [Administration](/admin/index) section.

## Finding things

- [Search & Filters](/guide/search): full-text search, typo tolerance, facets, and shareable search URLs.
- [Tags, Creators & Collections](/guide/organising): four ways to browse beyond search.

## Working with models

- [Models](/guide/models): the model page, the 3D viewer, editing details and the file tree.
- [Model Packages](/guide/packages): bundles that keep shared files together with independent child models.
- [Downloads](/guide/downloads): single files, whole-model ZIPs and resumable transfers.
- [Removing Models](/guide/removing): *remove from library* versus *delete the files*.

## Getting files in

- [Uploading](/guide/uploading): resumable uploads, folder drops and ZIP packs.
- [Importing from Model Sites](/guide/imports): paste a MakerWorld, Printables or Thingiverse link.

## Printing

- [Print Queue](/guide/print-queue): requests for things to print, one per line.
- [Print History](/guide/print-history): log what you printed, on what, and how it went.
- [Slicers & Printers](/guide/slicers-and-printers): **Open in…** your slicer and **Send** sliced files to a printer.

## Sharing and your account

- [Sharing](/guide/sharing): share one model by link.
- [Your Account](/guide/account): password, and connecting model-site accounts.

## What your role allows

What you can do depends on your role. A short version:

| | Viewer | Member | Admin |
| --- | :---: | :---: | :---: |
| Browse, search, download, like | ✅ | ✅ | ✅ |
| Add requests to the print queue | ✅ | ✅ | ✅ |
| Edit models, tags, collections, creators | | ✅ | ✅ |
| Upload and import | | ✅ | ✅ |
| Log prints, run the queue, send to a printer | | ✅ | ✅ |
| Trigger scans, resolve health problems | | ✅ | ✅ |
| Libraries, printers, users, settings | | | ✅ |

The full matrix is in [Roles & Permissions](/reference/roles).
