# Tags, Creators & Collections

Beyond search, the library can be explored in four more ways, all under **Browse** in the sidebar.

## Creators

![The Creators page](/images/guide/creators.png)

**Creators** shows who made what, with everything of theirs you own. A creator is created the first time you type their name into a model's **Creator** field; there is no separate setup step. Creator pages list their models, and the creator is a search filter.

## Tags

Tags arrive from filenames, sidecars and typing, so a library reliably grows *dragon*, *Dragon* and *dragons* all meaning the same thing. The **Tags** page is where you tame that.

![The Tags page with rename, recolour, merge and delete controls](/images/guide/tags.png)

| Action | What it does |
| --- | --- |
| **Rename** | Changes the tag everywhere it is used. |
| **Recolour** | Changes the colour shown on the tag. |
| **Delete** | Removes the tag from every model. |
| **Merge** | Folds one tag into another, so every model that had either ends up with the survivor. |

**Merge** is the one that matters. If you only tidy one thing, tidy tags.

Tag management needs the member role. Viewers can browse by tag but not change them.

## Collections

Collections group models however you like: a Kickstarter wave, a campaign, things to print next.

![Nested collections with model counts](/images/guide/collections.png)

- **Nestable.** A Kickstarter pledge is genuinely a collection of collections, so collections can sit inside collections.
- **Many-to-many.** A model can be in as many collections as you like.
- **Safe to delete.** Deleting a collection never touches the models or the collections inside it.

Add a model to a collection from its page, using the collections button in the header. Members and admins can create and edit collections; everyone can browse them.

![Adding a model to collections from its page](/images/guide/model-collections.png)

## Liked

![The Liked page](/images/guide/liked.png)

**Liked** is a private, per-user list. Press the heart on any model to add it; press it again to remove it. Nobody else can see your likes, and viewers can use them too.

## Counts hide missing models

Counts on all of these pages exclude models that are currently missing from disk. See [Search & Filters](/guide/search#counts-exclude-missing-models).

## Keeping tidy at scale

The [Library Health](/admin/health) page can list models with no creator, licence, tags or preview, so you can work through the gaps in bulk. Whether those are tracked is an [instance setting](/admin/settings).
